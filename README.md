# e-calendar

Family calendar application planned for AWS Amplify (temporary amplifyapp.com URL).

## Scope
- Combined read-only Outlook, Hotmail and Google calendar views
- Editable shared family events only
- Day, week and month views with per-calendar colours
- Secure family login and photo uploads
- Important event highlighting and wall-display mode

## Planned stack
Next.js, TypeScript, Tailwind CSS, AWS Amplify, Supabase, Microsoft Graph and Google Calendar API.

## Status
Repository initialized. Application source and deployment configuration are next. No production calendar accounts or secrets are connected.

## Security
Never commit OAuth secrets, access tokens or `.env.local` files.
